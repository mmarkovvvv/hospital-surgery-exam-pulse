# Пульс — госпитальная хирургия

Интерактивный учебный тренажёр для подготовки к экзамену по госпитальной хирургии.

## Сейчас внутри

- простой обзор пяти форматов подготовки без отдельного раздела программы курса;
- карточки с ответом, отметкой «знаю» и локальным прогрессом;
- 57 учебных билетов: 01–20 — основной тематический каркас, 21–40 — расширенная самопроверка, 41–57 — темы, найденные при сверке дополнительных учебных банков;
- 44 клинические задачи с пошаговым разбором и самооценкой;
- 48 карточек по билетам, алгоритмам, дифференциальной диагностике и красным флагам;
- тест из 40 вопросов с одиночным и множественным выбором, объяснением ошибок и итоговым процентом;
- 10 задач с изображением: реальные рентгенограммы, КТ, УЗИ и холангиограммы;
- список источников с прямыми ссылками;
- локальное сохранение прогресса в браузере.

## Запуск

Открой `index.html` в браузере или запусти локальный сервер:

```bash
python3 -m http.server 4173
```

Затем открой http://localhost:4173.

Для повторного запуска можно использовать `bash start-server.sh`.

## GitHub Pages

Проект — статический сайт без сборки, поэтому его можно открыть на телефоне через GitHub Pages. В репозитории уже добавлен workflow `.github/workflows/deploy-pages.yml`: после загрузки проекта в GitHub выбери в `Settings → Pages` источник `GitHub Actions`, затем отправь изменения в ветку `main`. GitHub опубликует `index.html` вместе с `app.js`, `styles.css` и папкой `assets`.

## Источники и медицинская точность

Контент MVP — учебное ядро по госпитальной хирургии, расширенное по тематике открытых материалов Российского университета медицины, дополнительным учебным банкам и клиническим рекомендациям Минздрава России. 57 билетов, 44 клинические задачи и 48 карточек — учебная структура приложения, а не дословно опубликованный кафедральный список экзамена. Перед добавлением лекарственных дозировок и детальных лечебных алгоритмов нужно сверять актуальную версию документа в [Рубрикаторе клинических рекомендаций](https://minzdrav.gov.ru/smartphone_apps_rubrikator_kr).

Изображения для задач взяты из Wikimedia Commons; на странице каждой задачи указаны исходный файл, авторство, лицензия и отмеченные изменения.

Приложение не заменяет обучение под руководством преподавателя, клинические рекомендации или медицинское решение.
